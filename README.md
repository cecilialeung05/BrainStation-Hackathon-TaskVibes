
# **TaskVibes**  
*A React-based productivity tool built during a BrainStation hackathon*  

## 📌 Overview  
TaskVibes is a **React-based productivity tool** designed for seamless task management, built using **JavaScript, Express.js, and API integrations**. It features an intuitive UI, real-time updates, and was developed through **pair programming** for efficient collaboration and problem-solving.  
![TaskVibes Screenshot](image.png)  
🔗 **GitHub Repository:** [TaskVibes](https://github.com/FarinazCodes/TaskVibes/tree/final)  

## 🚀 Features  
- **Customizable Dashboard** – Displays **greeting, date/time, daily quote, and weather updates**.  
- **Task Notepad** – Allows users to jot down important tasks.  
- **Focus Playlist** – Integrated with **SoundCloud** for productivity-friendly music.  

## 🛠️ Tech Stack  
- **Frontend:** React.js, JavaScript, Sass  
- **Backend:** Express.js, Node.js  
- **APIs:** Integrated various APIs for quotes, weather, and SoundCloud  

## 📋 Requirements  
- Must use **React** for frontend development  
- Must utilize an **API (Express.js)** for backend communication  
- **Pair Programming:** Collaborators took turns as **driver and navigator**  
- **Team:** Cecilia & Farinaz  

## ⚡ Challenges & Solutions  
- **HTTPS Issues** – Used a **proxy URL** to handle CORS-related problems.  
- **API Integration** – Implemented API calls efficiently to ensure smooth data retrieval.
